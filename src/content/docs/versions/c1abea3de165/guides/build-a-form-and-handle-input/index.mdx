## Outcome

Build named text fields, retained checkboxes, popup-backed selectors, a submit button, and a status label.

## Preconditions

The window input manager and UI must be initialized. Load `mle.ui.comp.text_dropdown_selector`. A field's `text.input` subtable constructs its `TextBox`; enabling does not construct one. Decide which entity coordinates focus using [Text input and focus](../../systems/ui/text-input-and-focus/): this snapshot does not enforce globally exclusive text focus.

## Construct the entities and components

Create text fields with stable `name`, size, padding, border, and `text = { text, input = {...} }`. Create checkbox rows with `table = { label, checked }` and `fn.setChecked`/`fn.toggle`. Create selectors by attaching `comp = dropdown(options, callback, origin)`. Put field names in the form root's retained `table`.

## Configure layout and visuals

Use a vertical list with fixed field widths/heights and consistent gaps. A multiline text input can set `multiline = true` and `ctrl_enter_newline = true`. Dropdown options render in a popup sized from the owner's normalized root bounds.

## Connect state and interaction

On a text field `lmb`, call a parent `focusTextInput(name)` function. That function first applies `text_input_disable` to every listed field and then `text_input_enable` to the selected one. Submit reads field `text`, checkbox `table.checked`, and selector `table.selected`, then updates the named status child. Enter submits and Tab completes according to Text input behavior; Escape blurs. Enable only focuses an existing `TextBox` and warns then returns when it is absent. Disable dereferences without that guard, so its prerequisite is `text.input` construction—not a prior enable.

## Verify the result

Click each field, type, toggle both checks, change dropdown choices, and submit. The visible status becomes `Submitted. Values printed to console.` and the values are printed by the demonstration.

## Cleanup and failure modes

Disable active input before removing the form when practical, then destroy the form root. Treat focus as explicitly coordinated, not exclusive by guarantee. Dropdown callbacks close their popup via deferred destroy. `valid()` does not query registry membership; never reuse retained wrappers after destruction, UI clear, or root replacement.
