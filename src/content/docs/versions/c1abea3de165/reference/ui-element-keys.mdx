The table covers all 101 normalized keys found in the pinned handler and structural branches. “Get” means `ew:get(key)` has a meaningful branch; absence means application-only unless a component-specific page proves otherwise. Invalid types generally log and leave prior state, but some nested parsers assert or Lua-error; validate reusable factory inputs before application.
