## First-party shader locations

- `res/shaders/present/`: final color correction.
- `res/shaders/model_pbr/`: model G-buffer, resolve, stylized, outline, wire, projection, and skinned vertex variants used by Model Test.
- `res/shaders/scene/`: scene/debug passes.
- `res/shaders/ui/`: rectangle, sprite, nine-slice, text SDF, background/border, and blur composition.
- `res/shaders/noise/` and root shader files: focused compute/primitive helpers.

Presence in this inventory does not imply every shader is automatically registered or covered by tests.

## Result and failure boundary

Recoverable surfaces include file/decode lookup results such as `FAILED_TO_OPEN`, `INVALID_ARGUMENT`, `NOT_READY`, and `NOT_FOUND`. Vulkan failures, unsupported reflection/accessor shapes, command-thread misuse, invalid render ordering, or missing queue ownership commonly assert or become unrecoverable.
