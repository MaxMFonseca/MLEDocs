Event order in the UI update is animation, hover, `on_update`, queued events, bounds, rendering, then destroy. Callbacks execute in the Lua state in which their component/table was created.

Additional phase callbacks are `on_create`, `on_update`, and `on_destroy`; named functions under `fn` execute only through `call` or application conventions. Raw C++ `EventListener` lifetime/unlisten semantics are separate from the retained Lua tables.

Do not treat `false` as a universally symmetric “remove callback” operation in this commit. Prefer building the intended callback table once, or replace/destroy the owning entity.
