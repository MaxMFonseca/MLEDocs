## Constructor-default distinction

`Keybinding{}` defaults to `Key::UNKNOWN`, `PRESSED`, and `NONE`. The convenience `KeyListener(callback, key, state)` constructor defaults its modifier argument to `ANY`. Set modifiers explicitly when the difference matters.

## Ownership summary

Key and scroll listeners unregister through RAII and use lifetime tokens during snapshot dispatch. `TextListener` unregisters in its destructor but does not track a listening flag or snapshot lifetime token. `TextBox` owns all of its listeners and registers them only while focused. Window events use retained `EventDispatcherST` listener handles.

See [Window and input](../../systems/window/) for the mental model and [Handle input, focus, and text](../../guides/handle-input-focus-and-text/) for the safe form sequence.
