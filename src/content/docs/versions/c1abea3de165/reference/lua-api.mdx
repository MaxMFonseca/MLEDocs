This is the Lua-visible surface registered by the pinned engine, not the complete C++ API. Objects borrowed from C++ remain valid only while their owner does. `mle_ui_Entt:valid()` only distinguishes a non-null entity identifier from `entt::null`; it does not query the registry or detect a stale wrapper. Never reuse a wrapper after requesting its destruction, clearing the UI, or replacing the UI root. Do not retain `mle_Image` beyond renderer ownership.

`uiHovered` is returned by `ew:get("hovered")` while the entity has the current hover component; hover callbacks themselves receive only `ew`. The engine also registers `mle_ui_Entt`, `mle_UI`, and `mle_Image` under their actual Lua names. See [`LuaUTGUI.h`](https://github.com/MaxMFonseca/MLE/blob/c1abea3de165032fe064300340807b7a6af388f8/src/mle/ui/LuaUTGUI.h) and [UI element keys](../ui-element-keys/) for table application rather than callable methods.
