Bare numeric values and the spellings below are parsed in the context of a target property. Dependencies and container pass order still determine the final rectangle; a valid spelling does not make a circular layout dependency valid.

For `TargetBound`, an unrecognized suffix becomes `DEFAULT`: a numeric prefix is retained, while a nonnumeric spelling receives the implicit value `1`; this branch does not log. Origin strings longer than two characters assert, and an unexpected origin character logs and contributes `0` on that axis.

The pinned `Entt::hasFitSize()` returns true on every path, so every internal bounds request currently propagates externally rather than selectively. Source identity: [`Types.cpp`](https://github.com/MaxMFonseca/MLE/blob/c1abea3de165032fe064300340807b7a6af388f8/src/mle/ui/Types.cpp).
