Lua usually constructs these through [element keys](../ui-element-keys/), not direct component constructors. An entity needs `Relationship` to participate in the retained tree. Bounds are derived in phases; rendering consumes a separate packet, and only one `Renderable` implementation belongs to an entity.

The 52 normalized component identities above include internal flag/phase types because they explain observable lifetime and invalidation. They are not promises of direct Lua construction. See [`Base.h`](https://github.com/MaxMFonseca/MLE/blob/c1abea3de165032fe064300340807b7a6af388f8/src/mle/ui/components/Base.h) and the focused system pages for sequencing.
