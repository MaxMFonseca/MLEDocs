MLE is under active development at this snapshot. It is not a finished engine, a stable SDK, or a drop-in framework. APIs, resource formats, and the project layout can change as systems are developed alongside a game.

Linux is the currently tested development platform. Windows support is intended because the main dependencies are cross-platform, but Windows builds are unverified at this commit. The helper scripts and some compiler and linker settings remain Linux-oriented.

Treat `in-development` as a compatibility warning, not a release tier. Pin integrations to the documented commit, review source changes before upgrading, and verify the build on the target environment.
