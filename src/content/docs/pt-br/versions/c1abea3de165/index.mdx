MLE é um motor de jogos em C++23 construído com Vulkan e Lua. Esta documentação descreve exatamente o código do commit [`c1abea3de165032fe064300340807b7a6af388f8`](https://github.com/MaxMFonseca/MLE/tree/c1abea3de165032fe064300340807b7a6af388f8), e não uma branch em constante mudança.

O MLE está em desenvolvimento ativo. Ainda não é um SDK estável, um motor finalizado nem um framework pronto para uso imediato. Linux é a plataforma de desenvolvimento testada atualmente; há intenção de suporte ao Windows, mas builds para Windows não foram verificadas neste commit.

O inglês é o idioma canônico da documentação. A cobertura em português brasileiro é adicionada página por página, e qualquer conteúdo em inglês usado como alternativa deve pertencer a esta mesma versão do MLE.
