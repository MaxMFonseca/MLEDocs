Esta seção documenta exemplos executáveis, suítes automatizadas, fluxos de fixtures e ferramentas de desenvolvimento que tornam o comportamento do MLE observável. Ela atende quem precisa validar um fluxo de forma interativa ou entender o que um aplicativo de teste distribuído com o projeto demonstra.

Cada página disponível informa se sua evidência é automatizada, interativa, gerada ou observada no código-fonte. A inclusão não classifica uma ferramenta ou funcionalidade do motor como estável, completa ou suportada.
